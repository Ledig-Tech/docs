---

<Steps>
  <Step title="Get access">
    Request a business account on [ledig.io](https://www.ledig.io/contact). After onboarding is approved, you can sign in to the dashboard.
  </Step>

  <Step title="Create an API key">
    In the dashboard, open **Settings** and create an API key. Choose **Full access**, **Read only**, or **Custom** permissions.

    The response contains `apiKey` and `secretKey`. The secret is shown once. Store it in your secret manager and never put it in browser code.
  </Step>

  <Step title="Check connectivity">
    The health route is public and needs no signature. Confirm you can reach the sandbox:

    ```bash
    curl https://api-staging.ledig.io/v1/health
    ```

    ```json
    { "status": "ok" }
    ```
  </Step>

  <Step title="Sign a request">
    Every other request carries `x-ledig-key`, `x-ledig-timestamp` and `x-ledig-signature`. The signature covers the timestamp, method, path and raw body.

    Read [Authentication](/auth/authentication) for the exact payload and working examples in Node.js and Python.
  </Step>

  <Step title="Explore the API">
    The full endpoint reference is being finalised. Until it is published, contact [admin@ledig.io](mailto:admin@ledig.io) for the current contract and a guided sandbox walkthrough.
  </Step>
</Steps>
