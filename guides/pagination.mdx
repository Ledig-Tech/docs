---
title: "Pagination"
description: "Read long lists one page at a time."
---

Transaction, quote and recipient lists use cursors to let you request the next page. Set `limit` to the number of records you want, from 1 to 100.

For example, start with:

```text
GET /v1/transactions?limit=25&sort=desc
```

Records appear in `data`. If more records are available, `pagination.nextCursor` contains the cursor for your next request. Pass that value back in the `cursor` query parameter without changing it.

## Read every page

This example assumes your `signedGet` helper signs the exact URL path and query using the [authentication instructions](/auth/authentication).

```js
let cursor;
const transactions = [];

do {
  const query = new URLSearchParams({
    limit: "100",
    sort: "desc",
    ...(cursor ? { cursor } : {}),
  });
  const response = await signedGet(`/v1/transactions?${query}`);
  if (!response.ok) {
    throw new Error(`Could not read transactions: HTTP ${response.status}`);
  }
  const page = await response.json();
  transactions.push(...page.data);
  cursor = page.pagination?.nextCursor ?? null;
} while (cursor);
```

- Stop when `nextCursor` is `null` or missing.
- Keep the same filters and sort order while requesting more pages.
- Do not create or decode cursors yourself.
- Use each record's ID to avoid duplicates if new transactions arrive while you are reading the list.

Some responses also include `previousCursor`. It can be `null` or missing when there is no previous page.

## Endpoints with pagination

| Endpoint | How results are returned |
| --- | --- |
| `GET /v1/transactions` | Cursor pages. |
| `GET /v1/quotes` | Cursor pages. |
| `GET /v1/recipients` | Cursor pages. |
| `GET /v1/wallets` | All your wallets, without pagination. |
| `GET /v1/managed-businesses` | Your managed-business directory, without pagination. |

For recipients, a `limit` above 100 is capped at 100. For example, `limit=150` returns at most 100 recipients. Zero, negative values and fractions are invalid. Other lists may reject values above their limit.

For temporary failures or rate limits, follow [Retries and idempotency](/guides/idempotency).
