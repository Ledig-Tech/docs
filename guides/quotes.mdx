title: "Quotes"
description: "Confirm executable pricing, payment fees, total debit and expiry."
---

A quote records the rate, amounts, fees and expiry for a conversion or payment. It does not move funds; a [transfer](/guides/transfers) executes the accepted terms.

## Discover currencies and rates

`GET /v1/currencies` returns configured currency codes, decimal precision and networks. It does not promise that every listed asset has a currently available payment route. `GET /v1/rates` returns indicative rates for reference; use a fresh quote for executable terms.

Send decimal strings at the source currency's precision. Do not round excess fractional digits silently or assume every currency uses two decimals. The server calculates the destination amount and validates its precision too.

## Discover payment methods and fees

These reads answer different questions:

| Operation                        | Use                                                                                           |
| -------------------------------- | --------------------------------------------------------------------------------------------- |
| `GET /v1/quotes/payment-options` | Discover eligible deposit or withdrawal methods for the currency, amount and destination.     |
| `GET /v1/payouts/catalogue`      | Display published payout fee bands, independently of whether sending is currently available.  |
| `POST /v1/payouts/fee-estimate`  | Estimate the fee for an amount and exact crypto network, without creating a quote or payment. |
| `GET /v1/quotes/payout-fees`     | Display the current customer payout-fee schedule, including internal Ledig transfers.         |

These discovery and fee operations require `quotes:read`; product access is checked separately.

For an external payout, supply `type=withdraw`, the destination `currency` and your approved `recipientId` to payment options. An optional `amount` filters options by limits. For crypto, include the matching `chain`. For an internal Ledig payment, supply `businessId` instead of `recipientId`; those two selectors are mutually exclusive.

Choose a value from the returned `paymentMethodIds` array for `payOut.paymentMethodId`. The option's own `id` is not the payment method ID. Preserve its `invoiceRequired` association when presenting choices. An empty list means no eligible option for that request.

If the selected option requires an invoice, include its valid `payOut.invoiceDocumentId` after completing the agreed dashboard or integration upload flow. Invoice-upload endpoints are not part of this published reference; contact Ledig to arrange that flow before using an invoice-required route. Do not invent a document ID or try to bypass the requirement with another method. `payOut.transferPurpose` remains optional; it does not replace the invoice.

The fee estimator is a non-mutating POST available with `quotes:read`, including a Read Only key. It requires `currency`, `payoutType` and a positive decimal `amount`; crypto also requires the exact `network`. A visible catalogue `bandId` can resolve an ambiguous band selection. A band is not permission to execute a payout.

Show pricing availability and payout availability separately. A priced band may remain visible while sending is unavailable, and an out-of-range amount can return `amountWithinLimits: false`. Missing or ambiguous pricing must not become a zero fee. Fetch a quote to confirm executable terms; do not cache these private responses or calculate the authoritative fee in your client.

## Create the quote

Illustrative request using an approved recipient and a payment method returned by discovery:

```http
POST /v1/quotes
Content-Type: application/json
```

```json
{
  "reference": "example_order_reference",
  "sourceCurrency": "USDT",
  "destinationCurrency": "NGN",
  "sourceAmount": "100",
  "payOut": {
    "type": "fiat",
    "recipientId": "RECIPIENT_ID",
    "paymentMethodId": "PAYMENT_METHOD_ID"
  }
}
```

| Field                                   | Meaning                                                       |
| --------------------------------------- | ------------------------------------------------------------- |
| `sourceCurrency`, `destinationCurrency` | Enabled currency codes for this request.                      |
| `sourceAmount`                          | Positive decimal string at the source currency's precision.   |
| `reference`                             | Optional reference, up to 64 characters.                      |
| `payOut`                                | Destination instruction; required for same-currency payments. |

For `payOut.type: fiat` or `crypto`, use an approved `recipientId` and eligible `paymentMethodId`. For crypto, include `chain` when required by the selected destination. A conversion between currencies can omit `payOut` when the converted amount stays in the Ledig balance.

## Read fees and the total debit

Read the returned fields together rather than adding a displayed fee a second time:

| Field                                  | Meaning                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `sourceAmount`                         | Conversion or payment principal in the source currency.                                                 |
| `destinationAmount`, `rate`            | Accepted destination amount and rate. Use the returned amounts; do not recompute from indicative rates. |
| `feeAmount`, `feeCurrency`             | Conversion fee, expressed in the source currency.                                                       |
| `sourceDebitAmount`                    | Principal plus conversion fee only.                                                                     |
| `payoutFeeAmount`, `payoutFeeCurrency` | Payout fee in the payout currency.                                                                      |
| `payoutFeeSourceAmount`                | That payout fee expressed in the source currency.                                                       |
| `totalFeeAmount`, `totalFeeCurrency`   | Conversion fee plus payout fee expressed together in the source currency.                               |
| `totalSourceDebitAmount`               | Total source debit, including both accepted fee components.                                             |

For example, if the accepted source principal is `100`, conversion fee is `1` and payout fee in source currency is `0.5`, `sourceDebitAmount` is `101`, `totalFeeAmount` is `1.5` and `totalSourceDebitAmount` is `101.5`. Do not add `payoutFeeAmount` again to that total, and do not add amounts expressed in different currencies.

This arithmetic illustrates returned fields; it is not a fee schedule. The quote fixes the customer terms. Display `totalSourceDebitAmount` before confirmation and retain the quote ID and `expiresAt`.

## Pay a Ledig business

Look up `GET /v1/ledig-businesses/{businessId}` with the exact destination ID and ask the sender to confirm the returned business name. This is not a search directory.

Create the quote with this `payOut` shape:

```json
{
  "type": "ledig",
  "businessId": "DESTINATION_BUSINESS_ID",
  "paymentMethodId": "ledig"
}
```

Do not send `recipientId` or `chain`, and do not create a saved recipient for this flow. The destination must be eligible; sending to the same financial profile is rejected. Eligibility is checked again when the transfer executes.

## Expiry and readback

`expiresAt` controls first execution. `GET /v1/quotes/{id}` reads the quote; `GET /v1/quotes` lists quotes using [cursor pagination](/guides/pagination).

A quote is consumed once. If an unused quote expires, obtain new terms. If transfer creation might already have succeeded, reconcile or replay that transfer using its original identifiers before creating a replacement quote. A retained transfer can still be recovered after its original quote expires; see [transfer retries](/guides/transfers#retries).

`payIn.type: temporary_bank_account` is reserved and returns `501 NOT_IMPLEMENTED`. Deposit-method discovery does not enable deposit quote execution.
