title: "Quotes"
description: "Price a conversion or payout and get executable terms."
---

A quote fixes the rate, the destination amount and an expiry. Nothing moves until a [transfer](/guides/transfers) consumes the quote.

## 1. Choose a payment method

For a payout, list the payment options for the corridor:

```http
GET /v1/quotes/payment-options?type=withdraw&currency=NGN&amount=100000
```

| Query | Required | Meaning |
| --- | --- | --- |
| `type` | Yes | `deposit` or `withdraw` |
| `currency` | Yes | Destination currency code |
| `amount` | No | Amount to check against the option's limits |

Each option returns a stable `paymentMethodId`, its channel, name, description, currency, fees, minimum and maximum amounts, and whether conversion is supported. Pass one of its `paymentMethodIds` in the quote's `payOut`.

## 2. Create the quote

```http
POST /v1/quotes
Content-Type: application/json
```

```json
{
  "reference": "order-1042",
  "sourceCurrency": "USDT",
  "destinationCurrency": "NGN",
  "sourceAmount": "100",
  "payOut": {
    "type": "fiat",
    "recipientId": "rcp_example",
    "paymentMethodId": "pm_example"
  }
}
```

| Field | Required | Notes |
| --- | --- | --- |
| `sourceCurrency` | Yes | Currency you are sending |
| `destinationCurrency` | Yes | Currency you are receiving or paying out |
| `sourceAmount` | Yes | Positive decimal string, up to 18 decimal places |
| `reference` | No | Your reference, 1–64 characters |
| `payOut` | No | Required for a same-currency payout; see below |

`payOut` accepts:

| Field | Required | Notes |
| --- | --- | --- |
| `type` | Yes | `fiat`, `crypto` or `ledig` |
| `recipientId` | For `fiat` and `crypto` | An approved [recipient](/guides/recipients) |
| `businessId` | For `ledig` | Exact Ledig business ID, confirmed with `GET /v1/ledig-businesses/{businessId}` |
| `paymentMethodId` | Yes | From the payment options response. For `ledig`, use `ledig` |
| `chain` | No | Crypto network, when the destination needs it. Not allowed for `ledig` |
| `narration` | No | Description sent with the payout |

The response contains the quote ID, the source and destination amounts, the rate, the status and `expiresAt`:

```json
{
  "status": "success",
  "data": {
    "id": "qte_example",
    "reference": "order-1042",
    "sourceCurrency": "USDT",
    "destinationCurrency": "NGN",
    "sourceAmount": "100",
    "destinationAmount": "159000",
    "rate": "1590",
    "status": "pending",
    "expiresAt": "2026-10-22T09:05:00.000Z",
    "createdAt": "2026-10-22T09:00:00.000Z"
  }
}
```

The server calculates `destinationAmount`. Never calculate it from the indicative rates endpoint: a rate is a reference, a quote is executable.

## Pay a Ledig business

A direct internal transfer pays another Ledig business without saving a recipient. Use it when the destination is a Ledig business and you have its exact business ID.

1. Look up the ID to confirm the business name:

```http
GET /v1/ledig-businesses/business_destination
```

```json
{
  "status": "success",
  "data": {
    "id": "business_destination",
    "name": "Example Trading Limited"
  }
}
```

The lookup is exact; it is not a directory or partial-name search. Ask the sender to confirm the returned name before creating the quote.

2. Create the quote with `payOut.type: "ledig"`:

```json
{
  "sourceCurrency": "USDT",
  "destinationCurrency": "NGN",
  "sourceAmount": "100",
  "payOut": {
    "type": "ledig",
    "businessId": "business_destination",
    "paymentMethodId": "ledig"
  }
}
```

- Send exactly one `businessId` with `paymentMethodId: "ledig"`. Do not send `recipientId` or `chain`.
- The source profile must be active and eligible for payouts. Destination eligibility and compliance are checked again during execution.
- A transfer to the same financial profile is rejected.
- `GET /v1/quotes/payment-options` accepts an optional `businessId` for internal payout discovery. It is mutually exclusive with `recipientId`.
- The quote's `payOut` metadata contains the business ID and name; private execution fields are not exposed.

## Rules

- A quote that converts between currencies can omit `payOut`. A quote that pays out in the same currency must include it.
- For `payOut.type: "ledig"`, use `businessId` and `paymentMethodId: "ledig"`; do not send `recipientId` or `chain`.
- `payIn` with `type: "temporary_bank_account"` is reserved but **not implemented**. Requests that send it return `501 NOT_IMPLEMENTED`.
- A quote is single-use. A transfer consumes it, and a consumed or expired quote cannot be used again.
- `expiresAt` is authoritative. Create a new quote rather than retrying an expired one.
