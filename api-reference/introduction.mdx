## What will be published

The reference will cover the operations available to authenticated business integrations:

- supported currencies and networks
- indicative rates
- ledger balances
- fiat funding accounts
- crypto deposit wallets
- recipients
- payment options and quotes
- transfers
- transaction history

Each operation will list its method, path, permission, request schema, response schema and errors.

## Until then

- Base URL: `https://api-staging.ledig.io`
- Authentication: [HMAC signing with an API key](/auth/authentication)
- Errors: [response envelope and codes](/errors/errors-and-troubleshooting)

Contact [admin@ledig.io](mailto:admin@ledig.io) for the current contract and a guided sandbox walkthrough. Do not build against older endpoint documentation; it describes a different platform.
