## Authentication

Every operation except `GET /v1/health` requires a business API key and an HMAC-SHA256 signature. Each operation lists its required scope under **Required scope**.

Read [Authentication](/auth/authentication) for the exact payload, required headers and working examples.

## What is public

This reference covers customer operations only:

- currencies, rates and balances
- fiat funding accounts and crypto deposit wallets
- recipients
- payment options, quotes and transfers
- transaction history

Dashboard, onboarding, API-key management and staff endpoints are not part of the public machine API and do not appear here.

## Errors

Every error uses the shared envelope `{ "status": "error", "message": string, "code": string }`. See [Errors and troubleshooting](/errors/errors-and-troubleshooting) for codes, limits and retry rules.
