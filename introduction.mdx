## The payments engine

Ledig's payments engine lets your business receive funds, hold balances, convert currencies and send payments through one API.

- **Receive funds:** get bank account details and crypto deposit addresses.
- **Hold balances:** see how much you can use in each currency and how much is reserved for payments in progress.
- **Convert currencies:** get a quote, review its rate and fees, then confirm the conversion.
- **Send payments:** pay a bank account, mobile money account, crypto wallet or another Ledig business, using the options available to your business.

Ledig also has a separate [onchain derivatives engine for FX hedging](https://docs.derivatives.ledig.io/). This documentation covers the payments engine.

## Get access

Create a business account through [ledig.io](https://www.ledig.io/contact) and complete onboarding. Your business administrator can then create an API key in the dashboard and choose its permissions.

Store your API key and secret on your server. Follow the [quickstart](/quickstart) to make your first request.

## Environments

| Environment | API URL | Use it for |
| --- | --- | --- |
| Sandbox | `https://api-sandbox.ledig.io` | Testing your integration with sandbox credentials. |
| Live | `https://api.ledig.io` | Processing real payments with live credentials. |

Use the API key issued for the environment you choose. Keep sandbox and live credentials, recipients and other resource IDs separate.

For the examples in these guides, set `LEDIG_API_BASE_URL` to your chosen API URL. Start with Sandbox:

```bash
export LEDIG_API_BASE_URL="https://api-sandbox.ledig.io"
```

Contact [support@ledig.io](mailto:support@ledig.io) for sandbox access and test-funding instructions.
