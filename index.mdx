## What the API covers

| Area | What you can do |
| --- | --- |
| Balances | Read available and reserved balances per currency |
| Currencies and rates | Discover supported currencies, networks and indicative rates |
| Funding | Read fiat funding instructions and create crypto deposit wallets |
| Recipients | Register and manage payout destinations |
| Quotes | Request executable pricing with an expiry |
| Transfers | Execute a quote and follow its status |
| Transactions | Read the customer transaction history |
